# 아마추어 무선사를 위한 허수 j (imaginary-j)

회로도, 안테나 분석기, NanoVNA, SDR 화면에 나오는 j를 읽을 수 있도록 허수의 역사, 의미, 무선에서 쓰이는 곳을 차례로 설명하는 한 페이지짜리 HTML 해설입니다.

## 구성

1. 수직선에는 자리가 없다
2. 허수의 역사: 방정식에서 교류 회로까지 (카르다노, 봄벨리, 베셀·아르강·가우스, 슈타인메츠, 스미스 차트)
3. i를 곱하면 90° 돈다 — 그림 「수직선에서 i 찾기」, 실험 ① 곱셈으로 돌리기
4. 흔한 함정 두 가지
5. 오일러 공식을 회전으로 유도하기
6. 교류는 돌아가는 화살표의 그림자 — 실험 ② 페이저
7. 코일과 콘덴서: jωL과 −j/ωC — 부품 그림, 실험 ③ 부품 애니메이션·위상·전력 p = v·i
8. 안테나 임피던스 R + jX와 SWR — 다이폴 그림, 실험 ④ 임피던스 평면 + 스미스 차트
9. 계측기 화면에서 j 읽기 — 실험 ⑤ VNA와 안테나 분석기(부호 없는 X) 화면
10. SDR의 I/Q, 위상형 SSB — 수신기·송신기 블록도, 실험 ⑥ I/Q 회전, 실험 ⑦ 더하면 LSB 빼면 USB
11. 원자가 내는 전파 (21 cm 선 그림, 세슘 시계, MRI)
12. 덤: iⁱ
13. 정리: j 한 장 요약

듣기는 「교과서 속 공식」과 같은 방식입니다. 맨 위의 ▶ 처음부터 듣기, 단원마다 ▶ 이 단원 듣기 버튼이 있고, 아래 재생 막대에서 이전·다음 문단, 일시정지, 속도(0.8~1.2×)를 조절합니다. 대본은 화면 글이 아니라 문단 단위로 따로 쓴 해설이며, 읽는 문단으로 화면이 따라가고 실험 상자도 대본에 맞춰 움직입니다. 블로그(iframe) 삽입 규약도 같은 것을 씁니다.
